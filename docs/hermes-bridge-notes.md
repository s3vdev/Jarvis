# Reusable notes: bridging a voice frontend to an installed Hermes CLI

- Inspect the installed `hermes chat --help` and `hermes --help`, not just generic examples. Global `-z` can automatically bypass approvals. Jarvis keeps one Hermes process warm and sets `HERMES_SINGLE_QUERY_SESSION=1` so unattended approvals stay deny. Never substitute `--yolo` or `HERMES_YOLO_MODE` for an approval integration.
- Reuse the existing profile and provider through the CLI. Do not copy OAuth tokens or configure a second provider account. Pin `-p default` when the task explicitly requires that profile.
- Parse JSONL by event type. Only a successful terminal `result` record's `text` is a spoken answer. Treat diagnostics, tool events, intermediate text, missing results, nonzero exit codes and timeouts separately. Never retry an action automatically just because its final response failed.
- A noninteractive frontend cannot answer interactive approval prompts. Verify the actual approval implementation and fail closed when the unattended policy allows bypass. Limit enabled toolsets, preserve ordinary guards and explain that this is not an OS sandbox or a read-only shell. An approval-only probe can verify denial without executing a dangerous action. A yes in the Jarvis window may only confirm a local allow-listed open. It must never approve a Hermes tool.
- Persist the returned explicit session ID in frontend-owned state, validate ownership and ID syntax, and pass only `--resume ID`. Never use `latest` or bare `--continue`; never silently create a replacement session after a resume failure.
- Use `--ignore-rules` when the frontend must not inject the user's global memory/project instructions; provide its concise persona explicitly. This does not isolate credentials or move the profile's transcript database.
- Finder starts with a reduced PATH. Prefer a stable installed launcher plus a checked executable fallback, and test with `PATH=/usr/bin:/bin:/usr/sbin:/sbin`.
- TDD the event parser, session restart, unsafe-policy refusal and timeout handling. Then opt in to a real account smoke test with a harmless read-only tool call, a second-turn recall check and final-text-only speech synthesis. Save actual stream evidence, never fabricated provider output. Keep smoke sessions separate from the user's voice session.
- Verify launch, HTTP readiness and non-TTY exit without recording the microphone. A pause sends the question; the name is optional unless settings require it. Spoken stop or the pause button must halt playback. Non-TTY runs do not open the microphone and do not start Hermes. Do not claim a live microphone-to-speaker test based only on synthetic audio.

Reference: official Hermes CLI documentation at https://hermes-agent.nousresearch.com/docs/reference/cli-commands; installed `hermes_cli/stream_json.py`, `hermes_cli/cli_agent_setup_mixin.py`, `tools/approval.py`. Re-check behavior after runtime updates.
